# PureRoots Farm

Welcome to the official repository for the PureRoots Farm delivery management ecosystem. 

## Project Overview
PureRoots Farm is an innovative agribusiness venture dedicated to producing and delivering fresh, organic dairy and farm products. This repository manages the infrastructure for our customer-facing delivery management application.

## Key Features
- **AI Voice Assistant:** Integrated conversational AI (Jerry) to assist customers.
- **Delivery Tracking:** Real-time location tracking for all farm deliveries.
- **Subscription Management:** Recurring order options for daily essentials including A2 cow milk, Murrah buffalo milk, and desi bilona ghee.
- **Customer Loyalty Rewards:** Built-in rewards program for returning subscribers.
